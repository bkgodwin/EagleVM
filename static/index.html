Linux Quick Reference — LXChoster Terminal

Keyboard Shortcuts
Ctrl+C interrupt / cancel running command Ctrl+Z suspend process to background Ctrl+L clear the terminal screen Ctrl+A jump to beginning of line Ctrl+E jump to end of line Ctrl+R reverse search command history Tab autocomplete paths and commands ↑ / ↓ browse command history Escape close this help panel
File System Navigation
pwdPrint current working directory path.
ls -lahList files with permissions, human-readable sizes, and hidden items.
cd <dir>Change into a directory. cd - returns to the previous directory.
mkdir -p <dir>Create a directory tree, including any missing parents.
cp -r src dstCopy files or directories recursively.
mv src dstMove or rename files and directories.
rm -rf <path>Remove files or directories recursively. Irreversible — use with care.
ln -s target linkCreate a symbolic link pointing to target.
find . -name "*.log"Find files matching a name pattern beneath the current directory.
du -sh *Estimate disk usage for each file and directory.
df -hShow mounted filesystem sizes and available space.
Viewing & Editing Files
cat filePrint the full contents of a file to the terminal.
less fileOpen a scrollable pager (press q to quit).
head -n 20 filePrint the first 20 lines of a file.
tail -n 50 filePrint the last 50 lines of a file.
tail -f fileStream new lines appended to a file in real time.
grep -R "text" .Search recursively for matching text across all files.
nano fileSimple terminal text editor. Save with Ctrl+O, quit with Ctrl+X.
vim fileAdvanced modal editor. Press i to insert, Esc then :wq to save and quit.
diff file1 file2Show line-by-line differences between two files.
wc -l fileCount the number of lines in a file.
Process & Resource Management
ps auxList all running processes with CPU and memory usage.
topInteractive real-time process and resource monitor. Press q to quit.
htopEnhanced interactive process viewer (may require install).
kill <pid>Send SIGTERM to a process, requesting graceful termination.
kill -9 <pid>Force-kill a process immediately with SIGKILL.
pkill <name>Kill all processes matching a name pattern.
bg / fgResume a suspended job in the background or foreground.
jobsList jobs running in the current shell session.
free -hDisplay total, used, and available RAM and swap.
uptimeShow how long the system has been running and load averages.
lscpuDisplay CPU architecture details and core count.
Networking
ip addrShow all network interfaces and their IP addresses.
ip routeDisplay the kernel routing table.
ss -tulpnList listening TCP/UDP sockets with process owners.
ping -c 4 hostSend 4 ICMP packets to test reachability of a host.
traceroute hostTrace the network path to a host.
curl -I URLFetch only HTTP response headers from a URL.
curl -O URLDownload a file from a URL, keeping its remote filename.
wget URLDownload a file from the web to the current directory.
ssh user@hostOpen an encrypted remote shell to another machine.
scp src user@host:dstSecurely copy a file to or from a remote host.
nslookup hostQuery DNS to resolve a hostname to an IP address.
Archiving & Compression
tar -czf out.tgz dirCreate a gzip-compressed tar archive from a directory.
tar -xzf archive.tgzExtract a gzip-compressed tar archive.
tar -tf archive.tgzList the contents of a tar archive without extracting.
zip -r out.zip dirCreate a zip archive of a directory.
unzip archive.zipExtract a zip archive to the current directory.
gzip / gunzip fileCompress or decompress a single file in place.
Permissions & Ownership
chmod 755 fileSet file permissions (owner rwx, group r-x, others r-x).
chmod +x fileMake a file executable for all users.
chown user:group fileChange the owner and group of a file or directory.
chown -R user dirRecursively change ownership of a directory tree.
umaskShow the default permission mask for new files.
idPrint the current user's UID, GID, and group memberships.
whoamiPrint the effective username.
Package Management (Debian / Ubuntu)
apt updateRefresh the local package index from all configured sources.
apt upgradeUpgrade all installed packages to their latest versions.
apt install pkgDownload and install a package and its dependencies.
apt remove pkgUninstall a package, keeping its configuration files.
apt purge pkgUninstall a package and remove its configuration files.
apt search termSearch available packages for a keyword.
apt show pkgDisplay detailed information about a package.
dpkg -lList all installed Debian packages.
dpkg -i file.debInstall a local .deb package file.
Systemd & Services
systemctl status svcShow the current status and recent log output of a service.
systemctl start svcStart a service immediately.
systemctl stop svcStop a running service.
systemctl restart svcStop then start a service (applies configuration changes).
systemctl reload svcReload service configuration without a full restart (if supported).
systemctl enable svcEnable a service to start automatically at boot.
systemctl disable svcPrevent a service from starting at boot.
systemctl list-unitsList all active systemd units.
journalctl -u svcShow the log output for a specific service.
journalctl -xeShow recent journal entries with explanations for errors.
journalctl -fStream new journal log entries in real time.
Development & Scripting
python3 script.pyRun a Python 3 script.
python3 -m venv envCreate a virtual Python environment in the env directory.
source env/bin/activateActivate a Python virtual environment.
pip install pkgInstall a Python package into the active environment.
node script.jsRun a JavaScript file with Node.js.
npm installInstall Node.js project dependencies from package.json.
bash script.shExecute a shell script with Bash.
chmod +x script.sh && ./script.shMake a script executable and run it directly.
envList all environment variables currently set.
export VAR=valueSet an environment variable for the current session and child processes.
historyShow previously entered commands with line numbers.
uname -aPrint kernel version, architecture, and OS build information.
