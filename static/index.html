LXChoster

Spin up a temporary Proxmox LXC shell session directly in your browser.

  • Click Launch Session to clone a temporary container from a template.
  • Connect instantly to an interactive root terminal in the web page.
  • When the session ends, the temporary container is destroyed automatically.
Container: - IPv4: - Session remains available for a limited reconnect window after disconnect.

Linux command and service help

  • pwd — print your current working directory path.
  • ls -lah — list files with permissions, size, and hidden items.
  • cd <dir> — change into another directory.
  • mkdir -p <dir> — create directories, including parents when needed.
  • cp -r src dst — copy files/directories recursively.
  • mv src dst — move or rename files/directories.
  • rm -rf <path> — remove files/directories recursively (dangerous).
  • cat file — print file contents quickly.
  • less file — open a scrollable file viewer.
  • head -n 20 file — show the first lines of a file.
  • tail -f file — follow new lines appended to a file/log.
  • grep -R "text" . — search recursively for matching text.
  • find . -name "*.log" — find files matching a name pattern.
  • du -sh * — estimate disk usage for files/directories.
  • df -h — show mounted filesystem usage.
  • free -h — display RAM and swap usage.
  • ps aux — list active processes.
  • top — interactive process and resource monitor.
  • kill <pid> — terminate a process by PID.
  • chmod 755 file — change file permissions.
  • chown user:group file — change file owner and group.
  • tar -czf archive.tgz dir — create a compressed tar archive.
  • curl -I https://example.com — inspect HTTP response headers.
  • wget URL — download a file from the web.
  • ssh user@host — connect to another machine via SSH.
  • ip addr — show network interface addresses.
  • ss -tulpn — list listening sockets and owners.
  • ping host — test network reachability to a host.
  • journalctl -xe — inspect recent systemd logs.
  • systemctl status service — inspect a systemd service status.
  • systemctl start|stop|restart service — manage systemd services.
  • service name status — SysV compatibility wrapper on some distros.
  • crontab -e — edit scheduled user cron jobs.
  • nano file — simple terminal text editor.
  • vim file — advanced modal text editor.
  • python3 — start the Python interpreter.
  • apt update && apt install pkg — refresh repositories and install package.
  • dpkg -l — list installed Debian packages.
  • uname -a — show kernel and OS build details.
  • history — show command history in current shell.
